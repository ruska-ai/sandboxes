Last week my agent kicked off a recursive build loop. CPU hit 100%, swap thrashing, SSH frozen.

The fix was 2 lines in `docker-compose.override.yml`:

```yaml
deploy:
  resources:
    limits:
      cpus: "2.0"
      memory: 4G
```

😅 That's it. Every #OpenHarness sandbox now gets a 𝐡𝐚𝐫𝐝 𝐜𝐞𝐢𝐥𝐢𝐧𝐠. Agent hits the wall → container throttles → host stays alive.

🔧 I run `NAME=dev` and `NAME=client` side by side. Without limits, one runaway build starves the other. With them, both get their fair share.

📌 Steal this override. Pair it with the quickstart:

```bash
git clone https://github.com/ryaneggz/open-harness.git && cd open-harness
make NAME=dev quickstart
```

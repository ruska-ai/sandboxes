Same refactoring task. Two approaches.

❌ System prompt: buried in a dashboard, no version history, gone when the session ends.
✅ AGENTS.md: lives in the repo, survives `git diff`, every agent reads it on boot.

🔧 12 lines of markdown beat a 200-word prompt on accuracy (agent followed 𝘦𝘷𝘦𝘳𝘺 constraint), iteration speed (edit a file, not a settings panel), and maintainability (PR review catches bad instructions before they ship).

Three agents — Claude Code, Codex, Pi Agent — all read the same 12 lines in my #OpenHarness sandbox.

```bash
git clone https://github.com/ryaneggz/open-harness.git && cd open-harness
```

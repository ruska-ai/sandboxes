I spent 20 minutes hunting down temp files my agent scattered across the container — `/tmp`, `/root`, `/var/cache`. All legitimate work, just everywhere.

Added one line to `AGENTS.md`:

```
Never write to any path outside /workspace/.
```

That's it. Next session, every output landed in the workspace bind mount. Cleanup became `docker rm`.

#OpenHarness mounts `/workspace` as the persistent volume — anything outside it vanishes with the container. The constraint just makes the agent know that.

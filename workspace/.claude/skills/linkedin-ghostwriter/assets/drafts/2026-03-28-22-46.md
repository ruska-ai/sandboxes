I'd been avoiding running exploratory queries against production data. Too risky, too many things to break.

😅 Then I mounted a `pg_dump` replica into my #OpenHarness sandbox and turned the agent loose.

🔧 It scanned 23 tables, cross-referenced every foreign key, and flagged 3 orphaned references in `orders` pointing to deleted `customers` rows. Records from 2024 that nobody noticed.

🧠 No production risk. The replica lives inside a disposable container — the agent can `DROP TABLE` and I just rebuild in 90 seconds with `make NAME=dev quickstart`.

📌 Logged every finding in `MEMORY.md` so the next session starts with the full audit trail.

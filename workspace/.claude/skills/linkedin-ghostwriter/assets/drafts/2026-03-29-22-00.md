I added 4 lines to my #OpenHarness agent's HEARTBEAT.md:

```
### Env Audit
- grep .env files for variables not referenced in src/
- cross-check against docker-compose.yml
- file an issue for each orphan
```

🧠 The agent didn't need a security scanner. It needed `grep` and a schedule.

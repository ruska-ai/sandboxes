One heartbeat task: "lint, test, check deploy." The agent ran lint, hit a failure, and never got to the other two.

😅 Three nights in a row.

I split it into 𝐬𝐜𝐨𝐩𝐞𝐝 blocks:

```
## Task 1: Lint
- npm run lint --fix → commit fixes

## Task 2: Test
- npm test → open issue on failure

## Task 3: Deploy Check
- curl $STAGING_URL → alert if unhealthy
```

🔧 Each task runs independently — one failure doesn't kill the cycle
📌 First morning after the split: 14 lint fixes committed, 1 test regression caught, deploy status green

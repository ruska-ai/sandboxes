Ran 5 named #OpenHarness sandboxes on a 4GB Hetzner VPS for 7 days. Each with its own SOUL.md, its own heartbeat cycle.

📈 The breakdown:
🔧 4 sandboxes sat at ~380MB idle, spiking to ~620MB during builds
🔧 `NAME=research` hit 1.2GB running `npm install` + `docker build` simultaneously — OOM killed on day 3

😅 Fix was one line in `docker-compose.override.yml`:
```
mem_limit: 768m
```

📌 Try it:

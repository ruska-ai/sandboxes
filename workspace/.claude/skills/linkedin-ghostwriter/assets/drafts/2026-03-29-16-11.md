My agent needed to build a Docker image inside the sandbox. Without Docker socket access, it just… couldn't.

🔧 One environment variable fixed it:

```
DOCKER=true make NAME=dev quickstart
```

That's it. Full Docker-in-Docker. Your #OpenHarness agent can `docker build`, `docker compose up`, spin up Postgres — all inside a disposable container that 𝘯𝘦𝘷𝘦𝘳 𝘵𝘰𝘶𝘤𝘩𝘦𝘴 𝘺𝘰𝘶𝘳 𝘩𝘰𝘴𝘵.

🔥 𝐓𝐡𝐫𝐞𝐞 𝐀𝐠𝐞𝐧𝐭𝐬. 𝐎𝐧𝐞 𝐅𝐢𝐥𝐞. 𝐎𝐧𝐞 𝐌𝐢𝐧𝐮𝐭𝐞.

Spun up 3 #OpenHarness sandboxes on a refactor — routes, tests, docs. All humming. 47 commits in 20 minutes.

😅 Then agent 1 and agent 3 both touched `config/routes.ts` within 60 seconds. Git merge conflict. Agent 1 auto-resolved it 𝘸𝘳𝘰𝘯𝘨. Test suite: 14 failures.

🔧 The fix wasn't smarter agents. It was 𝘴𝘮𝘢𝘳𝘵𝘦𝘳 𝘣𝘰𝘶𝘯𝘥𝘢𝘳𝘪𝘦𝘴:
- Each sandbox gets its own branch (`make NAME=routes`, `make NAME=tests`)
- AGENTS.md declares file ownership: "You own `config/`. Don't touch `src/tests/`."
- Merge happens once, manually, after all three finish

📌 Next run: 52 commits, zero conflicts. Same 3 agents, same codebase.

Client's agent couldn't write to disk day one. 😅 Forgot workspace permissions. 10-minute fix, trust hit.

Now I run these before every #OpenHarness handoff:

1️⃣ `cat SOUL.md` — scoped to 𝘵𝘩𝘦𝘪𝘳 project?
2️⃣ `ls MEMORY.md` — exists and empty? No stale context.
3️⃣ `docker exec sandbox whoami` — `sandbox` user, not root
4️⃣ `make NAME=client quickstart` — full cold boot. Breaks here → breaks for them.

🧠 2 minutes. 90% fewer first-week tickets across my last 3 deployments.

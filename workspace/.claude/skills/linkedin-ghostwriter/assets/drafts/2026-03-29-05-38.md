Client needed a Postgres migration — 14 tables, new schema, live backfill. I spun up 3 named #OpenHarness sandboxes:

- `make NAME=schema quickstart` → wrote the new DDL
- `make NAME=backfill quickstart` → transformed and inserted 80k rows
- `make NAME=validator quickstart` → ran type checks against every migrated column

😅 Schema agent declared `revenue` as `VARCHAR`. Backfill agent happily stuffed dollar amounts into strings. Neither complained.

The validator caught it on row 1. Logged the mismatch, the column name, and the commit hash to `MEMORY.md`.

🧠 Two agents built the house. The third one found the crack in the foundation.

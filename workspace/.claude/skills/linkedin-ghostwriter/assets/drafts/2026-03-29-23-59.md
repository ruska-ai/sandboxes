People ask how I run agents 24/7 without a Kubernetes cluster. 😅 Here's the whole setup:

```
*/30 * * * * cd /opt/open-harness && make NAME=prod heartbeat >> /var/log/heartbeat.log 2>&1
```

🔧 That's it. One cron line on a $6 VPS. Every 30 minutes, the agent wakes up, reads `HEARTBEAT.md`, does its tasks, and goes back to sleep.

📌 What mine runs overnight:
- Checks staging for failing tests
- Syncs client Zoho→QuickBooks data
- Writes a summary to `MEMORY.md`

🧠 No Airflow. No Lambda. No scheduler dashboard. Just `cron` and a #OpenHarness Makefile target that's been running since day one.

Set `DOCKER=true` on a sandbox. Left for lunch. Came back to 4 new images and a multi-stage Dockerfile I never asked for.

😅 It spun up Postgres, Redis, and a custom API gateway — all inside a 𝐝𝐢𝐬𝐩𝐨𝐬𝐚𝐛𝐥𝐞 𝐜𝐨𝐧𝐭𝐚𝐢𝐧𝐞𝐫.

🔧 #OpenHarness mounts the Docker socket when you set `DOCKER=true`. Full 𝐛𝐮𝐢𝐥𝐝 𝐚𝐜𝐜𝐞𝐬𝐬 — images, networking, volumes. Nuke the sandbox, everything vanishes.

🧠 On your host, the worst case is 𝘦𝘷𝘦𝘳𝘺𝘵𝘩𝘪𝘯𝘨. In the sandbox, worst case is `docker compose down`.

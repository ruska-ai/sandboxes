Ran 3 sandboxes in parallel. One wrote to a shared volume the other two were reading.

😅 The build agent updated `package-lock.json` mid-install. Two agents crashed on corrupted state.

🔧 The fix — one line per service in `docker-compose.yml`:

```yaml
volumes:
  - ./workspace-\:/home/sandbox/workspace
```

`NAME=agent1`, `NAME=agent2`, `NAME=agent3`. Each sandbox gets its own mount. Zero shared state.

📌 3 sandboxes, 3 workspaces, 0 collisions. I've shipped this on every parallel run since.

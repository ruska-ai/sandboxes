First week running multiple agents, one rewrote my Makefile while another was reading it. 😅 Classic.

Now every #OpenHarness sandbox starts with this `AGENTS.md`:

```
# Agent: [name]
## Owns
- src/ and tests/
## Ignores
- .env, Makefile, SOUL.md
## Outputs
- PRs to feature branches only
- Logs to workspace/MEMORY.md
## Coordination
- Read other agents' MEMORY.md before starting
- Never modify files another agent owns
```

12 lines. Agents stopped colliding overnight.

📌 Steal this:
```
git clone https://github.com/ryaneggz/open-harness.git
make NAME=dev quickstart
```
